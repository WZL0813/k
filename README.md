# 木语 · 榫卯 — 木作构件数字典藏(演示版 v3)

> 面向"大学生创新创业大赛"木作项目的 Web 展示页。
> 参考「山海」文物类 App 的界面与交互,做一套**中式木作构件**的数字展示平台。
> 核心亮点:**卡片用"真实产品照",点击展开可 360° 旋转的三维模型;
> 「教学实训」可自动拆解 / 手动拆解(榫卯件),其余构件按工序步骤讲解。**

---

## 一、怎么看(打开方式)

**方式 A(推荐)**:本机已启动预览服务,浏览器访问:

```
http://localhost:4444/demo/index.html
```

**方式 B(免服务器,离线)**:直接双击打开

```
demo/index.html
```

> ⚠️ 3D 引擎(Three.js)走 CDN,需联网。断网时页面仍显示,卡片显示"木"字占位。
> 如需彻底离线,把 `three.min.js` 与 `OrbitControls.js` 放到 `demo/` 本地引用。

## 二、功能对照(对标「山海」App)

| 功能 | 本演示版 |
|---|---|
| 顶部标题 + 搜索栏 | 「木语 · 榫卯」+ 实时搜索 |
| 圆形分类图标 | 全部/榫卯/家具/建筑/器具/文房/乐器/更多 |

## 三、内置 30 件「中式木作」构件(跨流派,不止客家)

- **榫卯(可拆解·6)**:一斗三升斗拱 / 燕尾榫 / 十字榫方木 / 井字榫木架 / 鲁班锁 / 企口拼板
- **家具(6)**:榫卯长凳 / 圈背扶手椅 / 四平八稳方桌 / 鼓钉绣墩 / 双门木柜 / 博古架
- **建筑(4)**:格栅窗棂 / 木柱与柱础 / 垂花门簪 / 雀替
- **器具(10)**:木胎大碗 / 圆盘 / 茶杯 / 高足杯 / 梅瓶 / 盖罐 / 三足香炉 / 围棋罐 / 小罐 / 木梳
- **文房(3)**:木胎笔筒 / 木镇纸 / 木质印章
- **乐器(1)**:木鱼

> v3 更新:
> 1. 卡片换成 **3D 渲染的产品照**(真实好看),点击进入**可旋转三维模型**;
> 2. 浏览页构件一律**组装好**展示(不再散开);
> 3. **拆解移入「教学实训」**:6 件榫卯可"自动拆解"或"拖进度条手动拆解",其余构件按"选材→开料→成型→打磨→上蜡"工序步骤讲解;
> 4. 扩充到 **30 件**,产地覆盖 客家围屋、赣南、苏作、徽作、东阳木雕、广东木作、建盏等。
